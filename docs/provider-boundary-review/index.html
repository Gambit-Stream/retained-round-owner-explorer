Build your boundary record

Describe one integration boundary and name its owners. The summary counts completed fields and lists gaps. It does not rate suppliers or approve a launch.

The event recipient receives the provider message. The wallet owner authorizes its financial interpretation. The exception receiver takes unresolved work. The acceptance owner reviews the purchased integration against agreed criteria. Confirm each duty even if one person holds several roles.

Fields start blank. Data stays in current page memory and disappears on reload or Reset. Export saves JSON on your device. No form transmission, provider requests or wallet actions occur. Keep secrets and personal player records out of this worksheet.

Use an adapter revision to distinguish the proposed scope from the reviewed artifact. A populated field records an assertion; review its evidence before treating it as accepted.
