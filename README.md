# Retained Round Owner Explorer

An original, dependency-free fictional scenario model for late provider event ownership. It keeps the retained handler separate from the original wallet result. It performs no provider or wallet calls.

Live reference: https://gambit-stream.github.io/retained-round-owner-explorer/

Requires Node.js 23 or later for `node --test test/explorer.test.mjs`. Serve `docs` with any static HTTP server to inspect the UI. Pages source: `main`, `/docs`.

See CONTRACT.md for the input schema and decision boundaries. Five preset fixtures and the default JSON/CSV report are in docs/data. All labels are synthetic. No input combination authorizes a wallet effect or establishes production readiness. No private or client material is included.
